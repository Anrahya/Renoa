Renoa
GitHub Control Center
Open source · Self-hosted · AI agents

Your agents share one library and talk over one line.

Renoa is an open-source system for running AI agents on your own server. Add a plugin or skill once, and every agent can use it. RCP, Renoa’s own protocol, is the line between your apps and your agents, and between the agents themselves.

    AExtending

    When an agent needs something new, it adds it.

    Ask an agent for something it can’t do yet, like reading a Figma file, and it goes looking for a plugin that can.

    1. It searches the official MCP Registry for a plugin.
    2. It checks the provider’s own documentation before going further.
    3. It asks you to approve the connection, and to sign in.
    4. It adds the plugin to its tools and to the shared library.
    BShared library

    Add it once. Every agent can use it.

    Run as many agents as you need, each with its own job. Plugins and skills live in the host’s shared library, not inside any one agent.

    1. Agent A adds Figma. It goes into the library, once.
    2. The other agents use it too. No second install, no second sign-in.
    3. Skills are shared the same way: written once, used by any agent.
    4. What they learn about you follows you from agent to agent.
    CRCP

    One line between your apps and agents.

    RCP is Renoa’s own protocol. Discord, Telegram, GitHub and Control Center all connect the same way, and a task is never kept inside the app you started it in.

    1. A message in Discord reaches Agent A over RCP, and the reply comes back.
    2. Start in Discord and carry on in Control Center, right where you left off.

    Other apps, like WhatsApp, can be added the same way.

    “Connections are temporary. The task is not.”The rule RCP is built on

    DAgent to agent

    The same line runs between agents.

    Each agent works where its job is: Agent A in your Discord, Agent C in your family’s Telegram group. When one needs another, it asks over RCP, the same way you do.

    1. You ask Agent A in Discord to plan Friday dinner with your family.
    2. Agent A asks Agent C, which looks after the family group.
    3. Agent C checks with everyone in Telegram and finds a time.
    4. Agent A brings the plan back to you in Discord.
    EControl Center

    Run all of it from one place.

    Control Center is one more app on the line: every agent, what it is doing, and everything in the shared library.

    • See what every agent is doing, and talk to it.
    • Check scheduled jobs, and pause or resume them.
    • Restart an agent from here when something breaks.
    Get started

    Start with one agent and one app.

    Renoa is open source under MIT or Apache 2.0, and runs on your own server. Every agent and app you add after that shares the same library and the same line.
