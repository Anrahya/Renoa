# Logos

The Renoa mark: an ink core tile with six outlined tiles around it, one pulled out mid-swap.

- `renoa-mark-ink.svg`: single ink `#14161A` (`foreground` on Paper). Use on `background` and `card` in the Paper theme.
- `renoa-mark-paper.svg`: single ink `#F5F6F3` (`background` of Paper). Use on Graphite grounds.

Draw at 20px or larger; at 16px (favicons) it still reads as a rosette. Set the wordmark "Renoa" in Instrument Sans 600, -0.02em, at 0.8x the mark's height, 10px to its right. Never recolour the mark with a part pigment.
