# Plate

A plate frames a figure: a stage on the board lattice, and a caption strip with the figure number and one sentence about what is happening.

## Use it for
Diagrams and illustrations: the landing board, an agent's composition on its Overview, onboarding explanations, empty states.

## You provide
The figure number and title ("Fig. 1 · Agent A"), a one-sentence caption, and the drawing. Add `rn-board` to the stage to show the lattice of empty sockets.

## Rules
- A plate is the one bordered container in the system; use it for figures only, never to box ordinary content.
- Label illustrations as illustrations. Live data gets a timestamp and the Host as its source.
- If the figure moves, the caption strip carries a Pause control.
