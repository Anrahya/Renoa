# Kicker

A kicker opens a section: a letter in a hex, a mono label, and a rule that runs to the edge.

## You provide
A short label in the section's own words, and a letter when sections are figures in a sequence (A, B, C on the landing page, matching what the diagram shows).

## Rules
- Letters only when the sections are a real sequence the reader follows. Otherwise the label and rule alone.
- The hex outline is `muted-foreground` and the rule a `border` hairline, so the kicker marks a section without adding ink. On the landing page a stepping section adds its step dots after the rule.
