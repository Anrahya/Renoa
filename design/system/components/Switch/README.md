# Switch

A switch turns a standing behaviour on or off right away: a routine, a trigger, a plugin.

## You provide
A label that names the behaviour ("Morning briefing"), its current state, and the save result.

## Rules
- Use a switch only when the change applies immediately. Settings that need Save use a checkbox.
- The knob is square (`radius-xs`). Round shapes are reserved for live state.
- While a save is pending, disable the switch and show the pending state in words next to it.
